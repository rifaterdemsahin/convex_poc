Query Definition
convex/messages.ts 
import { query } from "./_generated/server";

export const listMessages = query({
  args: {},
  handler: async (ctx) => {
    return await ctx.db
      .query("messages")
      .order("desc")
      .take(50);
  },
});
React Hook
components/MessageBoard.tsx 
import { useQuery } from "convex/react";
import { api } from "../convex/_generated/api";

export function MessageBoard() {
  // Re-renders automatically when data changes
  const messages = useQuery(api.messages.listMessages);

  if (messages === undefined) return <Spinner />;

  return (
    <ul>
      {messages.map((m) => (
        <li key={m._id}>{m.author}: {m.text}</li>
      ))}
    </ul>
  );
}
How It Works
WebSocket subscription
Convex SDK opens one persistent connection. All useQuery hooks share it — no per-query sockets.
Differential updates
Convex only sends the changed rows, not the full result set. Bandwidth is proportional to the diff size.
Automatic invalidation
Any mutation that touches the queried table triggers re-execution on the server and a push to all subscribers.
