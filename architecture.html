Data Flow
1
Client subscribes
React component mounts → useQuery registers subscription over the existing WebSocket.
useQuery(api.messages.listMessages)
2
Query executes
Convex runs the handler, reads from DB, and streams the initial result to the client.
ctx.db.query("messages").order("desc").take(50)
3
Mutation fires
Any client calls sendMessage → mutation runs transactionally, commits to DB.
ctx.db.insert("messages", { text, author })
4
Reactive push
Convex detects the messages table changed → re-runs all affected queries → pushes diffs to every subscriber. Zero client polling.
∆ diff → push to 3 subscribers
